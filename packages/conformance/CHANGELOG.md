# Changelog of @swf/conformance

Each release of @swf/conformance and what it changed for those who use it. Versions follow semantic
versioning: before 1.0.0, a minor version may change the public API incompatibly and a patch
version never does; from 1.0.0, only a major version does.

## 0.1.0

The first release. Suites that check an adapter, a renderer or a compositor against the contracts, with reference mocks to run them against.

The backend suite's projection profiles no longer declare a mapping.
