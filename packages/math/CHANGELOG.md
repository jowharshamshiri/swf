# Changelog of @swf/math

Each release of @swf/math and what it changed for those who use it. Versions follow semantic
versioning: before 1.0.0, a minor version may change the public API incompatibly and a patch
version never does; from 1.0.0, only a major version does.

## 0.1.0

The first release. Vectors, unit quaternions, position/rotation/scale transforms, affine matrices, rays, axis-aligned boxes, and a seeded random sequence that is the same on every engine. The world is right-handed and +Y up; the default camera looks along -Z with +X to the right. Lengths are arbitrary world units.
