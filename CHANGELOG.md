# Changelog of @swf/diagnostics

Each release of @swf/diagnostics and what it changed for those who use it. Versions follow semantic
versioning: before 1.0.0, a minor version may change the public API incompatibly and a patch
version never does; from 1.0.0, only a major version does.

## 0.1.0

The first release. What a running presentation can report locally: each viewport's backend and capabilities, the fallbacks chosen and why, frame, attachment and scene-operation measures, scene density, resource health and the last typed errors; a trace of the workspace's operations to reproduce interaction bugs; and an export of both that discloses labels, binding keys and the host's data only when asked.
