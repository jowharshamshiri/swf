# Security boundary

SWF defines no trust model of its own: what content a page shows, from where, and with what
authority is the host's and the browser's to decide. Within that, the framework guarantees the
following about the input it reads and the data it reports. Each guarantee is held by the tests
named beside it.

| Guarantee                                                                                                                                                                                                                                                                                                                                | Held by                                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Snapshots are read as data.** A snapshot's size is checked before it is parsed; non-finite numbers, unknown or missing fields, data nested more than 64 levels, keys that could reach an object's prototype, cycles, broken references and over-limit extension state are refused, naming the path. Nothing in a snapshot is ever run. | `packages/persistence/test/document.test.ts`, `packages/core/test/snapshot.test.ts`, acceptance scenario 8                                                   |
| **Metadata is JSON under declared namespaces.** Node metadata keys are `host.*` or `ext.<id>.*` (with `swf.*` reserved), values JSON only, nested at most 64 levels, prototype keys refused.                                                                                                                                             | `packages/core/test/hierarchy.test.ts` (metadata)                                                                                                            |
| **Labels and host data are text.** Labels, titles, stand-in reasons and every value from the host are inserted as text; no package parses markup or evaluates code (`innerHTML`, `insertAdjacentHTML`, `DOMParser`, `srcdoc`, `eval`, `new Function`, inline event handlers).                                                            | `packages/backend-dom/test/text-only.test.ts` (scans every package's source), `packages/backend-dom/test/browser/labels.browser.test.ts`                     |
| **Cross-origin content stays the browser's.** The framework never synthesizes input into content; a cross-origin frame gets its input from the browser alone, and the framework never reads rendered pixels back.                                                                                                                        | `packages/backend-dom/test/browser/input.browser.test.ts`                                                                                                    |
| **Diagnostics leak no content.** Reports hold identifiers, counts and timings; an export or a trace leaves out labels, binding keys, tags, metadata and error messages unless the host discloses each, and nothing is sent anywhere. Adapters' payloads are never read.                                                                  | `packages/diagnostics/test/trace.test.ts`, `packages/diagnostics/test/diagnostics.test.ts`                                                                   |
| **Capabilities are scoped.** A module can be given only the scope it needs: read, mutate, persistence, binding or registration.                                                                                                                                                                                                          | `packages/core/test/events.test.ts` (reader), `packages/core/test/snapshot.test.ts` (persistence), `packages/presentation/test/registry.test.ts` (registrar) |
| **Modules run with the page's authority.** Projections, backends, adapters, policies and extensions are JavaScript the host loads; SWF does not sandbox them.                                                                                                                                                                            | ([Load modules on demand](../how-to/load-modules-on-demand.md))                                                                                              |

## Dependencies

What a host installs with the packages is listed, with each item's version, licence and
integrity, in every release's `dependencies/inventory.md` and CycloneDX SBOM; the release is
refused if any of it has a known vulnerability. The development tools are pinned to exact
versions and audited too; a high or critical vulnerability in them refuses a release, and the
others are listed in the inventory ([Release the packages](../how-to/release.md)).
